TrollStore。当前交付定位是简体中文设备测试包，尚未完成该设备上的验收，

## 已建立：独立固定输入轨迹

`ios/tests/browser_behavior.mjs` 已从上述独立上游 WASM 捕获轨迹。固定简体
语言、种子 `12345`、`Date.now() = 1788840000000`，每 tick 调用
`sdl_loop_tick(app, 1/60, 17)`。输入顺序是：

1. 330 tick 不按键。
2. 重复五次：按住 Z 三个 tick，然后松开 42 个 tick。
3. 再松开 100 个 tick；以上共 655 个预热 tick。
4. 连续 14000 tick 按住 Z、左 Shift 和左 Control。每次 tick 前，如果
   玩家存在，将无敌计时器写为 `previous=120`、`current=121`、`fractional=121`。

预热完成、每 600 个游戏 tick 和终点各记录一次，共 25 个检查点。两次独立
启动的状态前五项、18 个经济字段和两路 RNG 均一致。终点状态为
`[7, 2, 0, 2, 100]`，分数 `723283`，脚本 RNG 为 `seed=55606/calls=4008`。
内存布局由基线编译器生成，不套用原生平台的指针宽度。

报告为 `baseline-behavior.json`、`baseline-behavior-repeat.json` 和
`baseline-behavior-repeat-verification.json`。这些是**待原生程序对照的参考数据**，
目前不记录“原生轨迹一致”的结论。无敌写入沿用上游行为测试的方法，改变了
正常游戏条件；本轨迹既不是未修改原版 EXE 的结果，也不是缺失的历史 2.3 夹具。

原有历史行为期望值、录像夹具和上一发行版 WASM 未包含在当前源码分发中。
依赖它们的完整行为、录像存储和旧版画面比较没有获得通过结论，也没有用
候选程序生成的数据充当这些缺失的期望值。

## 原生检查：单独记录 Mac 执行结果

原生检查入口是 `ios/tools/native_checks.sh`。其检查范围为：

| 检查项 | 验证内容 |
| --- | --- |
| 调度与数值 | 固定 60 Hz 调度及数值截断的 SoftFloat 对照 |
| 触控策略 | 移动、慢速、Bomb、暂停、取消、菜单和对话输入 |
| 虚拟摇杆 | 径向死区、斜向限速、Z/S 同按、菜单选择、释放归中与区域拖动恢复 |
| 生命周期状态 | 前后台、音频中断、设置面板重叠时的暂停/恢复顺序及终止状态 |
| Apple 文本格式 | 数字区域设置、舍入方式和原生字符串指针 |
| 原生布局 | ANM 初始化、ECL 高地址返回、分数统计与文件布局 |
| ECL 跳转 | 负向跳转使用有符号位移，避免在 64 位平台误跳 4 GiB |

上述检查已在 Intel Mac、macOS 12.7.6、Xcode 14 的 Apple Clang 环境实际运行，
八组均通过；最终执行记录为私有报告 `native-checks-ready.log`。数值检查包含
738601 次精确转换与 261399 次保留回退，触控及生命周期检查包括设置面板。
它们是 Mac x86_64 原生单项检查，不是 iOS ARM64 真机执行记录；也不代表
原生固定轨迹、模拟器整合或完整游戏流程已通过。

## 模拟器与设备测试包记录

已在独立的 iPad mini 5 模拟器、**iOS 16.0** 实际运行原生程序，观察到中文
标题、角色/武器选择、第一关、玩家射击及敌人出现，状态记录 `screen=7`、
`stage=1`、`error=0`。横屏渲染输出为 2048×1536，游戏视口为
`0,0,2048,1536`，完整占满屏幕。横屏控制层覆盖在游戏上，竖屏保持 4:3。
这些是模拟器启动与第一关初期的集成证据，不能推断完整关卡和真机性能。

日志设置的原生集成检查实际调用设置按钮和导出行，展示系统分享面板，
验证游戏暂停、生成非空文本快照、取消分享后关闭设置并恢复回调。导出文本
已核实包含上次第一关运行和本次导出会话。此检查使用诊断版内部测试入口，
没有选择或发送给外部接收人，也不代表已手动验收所有 UIKit 触摸路径。

模拟器使用较慢的软件图形环境，低帧率和首次加载用时不能代表 iPad mini 5
实机速度。期间发现并修复 ECL 负向位移在 64 位指针上的错误；修复后第一关
运行未再触发该崩溃。最终设备包使用原版 th10.exe 图标、简体资源、ARM64
设备代码，最低系统 iOS 14.0；`TH10Diagnostics=OFF`，自动按键和测试入口
不进入设备包。本机日志与导出功能继续启用。

版本 0.1.0，构建 1。Mac 桌面交付文件名为
`TH10-iOS14-iPadMini5-Test.ipa`，精确 SHA-256、大小、签名及资源校验结果见
同名 `.manifest.json`。源码包排除原始 EXE、提取图标及其他私有资源。

设备包采用 TrollStore 对应的 ad-hoc 签名安装途径。打包检查应排除模拟器
Mach-O、开发诊断自动运行模式、Web 运行时负载、用户存档及资源哈希不一致。
这些属于包结构检查，安装结果仍需在目标 iPad 上确认。
